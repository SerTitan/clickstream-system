# Clickstream Analytics

## Введение

### Описание проекта
Проект Clickstream Analytics посвящён построению системы сбора и аналитической обработки пользовательских событий (clickstream) — кликов, просмотров страниц, переходов, действий в интерфейсе и других событий, возникающих при взаимодействии пользователя с веб-приложением.

**Объект разработки/исследования** — поток clickstream-событий, генерируемых пользователями в ходе работы с приложением, а также инфраструктура для его надёжной доставки, хранения и последующего анализа.

**Предмет разработки/исследования** — архитектура и реализация сервиса clickstream-аналитики: способы приёма и буферизации событий, организация передачи через брокер сообщений, проектирование схем хранения в аналитическом хранилище, подготовка данных для отчётности и визуализация результатов.

### Стек технологий
- PostgreSQL (метаданные для Airflow/Superset, витрина)
- ClickHouse (DWH)
- Kafka (3 брокера в режиме KRaft, транспорт событий)
- Spark
- Superset (BI/дашборды)
- Prometheus (сбор метрик)
- Grafana (визуализация метрик)
- Kafka UI (веб-интерфейс для Kafka)

## Запуск

### Требования
- Docker + Docker Compose

### Запуск одной командой
```bash
docker compose up -d
```

### Адреса сервисов (localhost)
- Kafka UI: http://localhost:8082
- ClickHouse HTTP: http://localhost:8123
- ClickHouse Native: localhost:9000
- PostgreSQL: localhost:5432 (db/user/password: meta/meta/meta)
- Airflow: http://localhost:8080
- Prometheus: http://localhost:9090
- Grafana: http://localhost:3001 (admin/admin)
- Superset: http://localhost:8088 (admin/admin)
